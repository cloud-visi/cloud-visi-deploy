# Share feedback if you want to

Use Cloud-Visi in whatever way fits your work. There is no required task list or target outcome.

You can share any of these:

- Something it helped you understand.
- Something you were trying to do but could not.
- A confusing word, page, or interaction.
- Information you wanted but could not find.
- A reason it did not fit your work.

You do not need to answer every point. A short note in your own words is enough.

For a technical problem, the application version and chart version help us identify the build. Open `http://127.0.0.1:8080/api/version` in your browser to see the application version. The chart version appears in `helm list`.

Public GitHub issues are visible to everyone. Keep private code, tokens, Terraform state, database exports, and unredacted logs out of public reports. Ask for a private reporting route when the example contains company information.
